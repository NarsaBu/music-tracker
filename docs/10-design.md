# 10 — Дизайн интерфейса: скевоморфизм

## 1. Концепция — «Hi-Fi стойка»

Интерфейс выглядит как домашняя аудиосистема конца 70-х — начала 80-х: корпус с деревянными боковинами, лицевые панели из шлифованного алюминия, тумблеры, светодиоды, VU-метры, LCD-дисплеи и полка с виниловыми пластинками.

Каждый экран — отдельный «блок» стойки:

| Экран | Метафора | Ключевые физические элементы |
|-------|----------|------------------------------|
| Лента новинок | Полка с пластинками | Карточка = конверт пластинки с обложкой; при наведении пластинка выдвигается из конверта |
| Подписки | Картотека / ящик с карточками | Карточки исполнителей с бумажной фактурой и «вкладками»; LED-индикатор статуса синка |
| Поиск исполнителя | Тюнер | Поле ввода в виде шкалы радио; результаты — «станции», score показан стрелкой-индикатором |
| Импорт | Кассетная дека | Зона drop в виде кассетоприёмника; прогресс — вращающиеся бобины + счётчик-LCD |
| Разбор импорта | Карточки с пометками | Неоднозначные строки — карточки с вариантами, выбор — «штамп» |
| Настройки | Задняя/передняя панель усилителя | Типы релизов — тумблеры; featuring — тумблер; частота дайджеста — поворотный переключатель (2 положения) с крупными метками; RSS — табличка с гравировкой ссылки |
| Ручная синхронизация | Кнопка питания / «Play» | Крупная выпуклая кнопка, при нажатии утапливается; VU-метр показывает прогресс прогона |
| Вход | Замок / ключ | Панель с замочной скважиной, поле пароля как гравированная плашка |

Принцип: **метафора помогает, а не мешает**. Каждый «физический» контрол — обычный доступный HTML-элемент (`<button>`, `<input type="checkbox" role="switch">`, `<input type="radio">`), только стилизованный. Никаких крутилок вместо полей ввода текста и чисел.

## 2. Материалы и фактуры

Все фактуры — CSS (градиенты, `box-shadow`, `filter`), без растровых изображений, кроме одной тайловой SVG-текстуры дерева и шума (`< 10 КБ`).

| Материал | Где | Реализация |
|----------|-----|------------|
| Шлифованный алюминий | Фон панелей | `repeating-linear-gradient` тонких полос + `linear-gradient` блика |
| Дерево (орех) | Боковины layout, шапка | SVG-текстура + тёплый градиент |
| Чёрный пластик | Кнопки, ручки | `radial-gradient` + внешняя тень |
| Бумага / картон | Карточки исполнителей, конверты | светлый тон + SVG-шум (`feTurbulence`) + лёгкая неровная тень |
| Стекло | LCD-дисплеи, VU-метр | тёмный фон, внутренняя тень, блик `linear-gradient` сверху |
| Подсветка | LED, шкалы | `box-shadow` с цветным glow |

## 3. Дизайн-токены

Хранятся как CSS custom properties в `src/shared/ui/theme/tokens.css`. Компоненты используют только токены — никаких «магических» цветов (DRY).

```css
:root {
  /* поверхности */
  --surface-panel:     #d9d9d6;           /* алюминий */
  --surface-panel-hi:  #f2f2ef;
  --surface-panel-lo:  #a9a9a4;
  --surface-wood:      #6b3f22;
  --surface-paper:     #efe6d2;
  --surface-display:   #1b2a1f;           /* стекло LCD */

  /* текст */
  --text-engraved:     #3a3a38;           /* гравировка на алюминии */
  --text-on-paper:     #2b241a;
  --text-display:      #9dff8a;           /* зелёный LCD */

  /* индикаторы */
  --led-on:            #ff5a2a;
  --led-ok:            #5dff6a;
  --led-warn:          #ffc23d;
  --led-off:           #4a2a22;

  /* объём */
  --bevel-raised:  inset 0 1px 0 rgba(255,255,255,.7), inset 0 -1px 0 rgba(0,0,0,.25), 0 2px 4px rgba(0,0,0,.35);
  --bevel-pressed: inset 0 2px 4px rgba(0,0,0,.45), inset 0 -1px 0 rgba(255,255,255,.3);
  --shadow-object: 0 6px 14px rgba(0,0,0,.35), 0 1px 2px rgba(0,0,0,.4);
  --glow:          0 0 6px currentColor, 0 0 14px currentColor;

  /* типографика */
  --font-label:   "IBM Plex Sans Condensed", system-ui, sans-serif;  /* гравировки, UPPERCASE, letter-spacing .08em */
  --font-body:    "IBM Plex Sans", system-ui, sans-serif;
  --font-display: "Share Tech Mono", ui-monospace, monospace;        /* LCD-счётчики, даты */
  --font-hand:    "Caveat", cursive;                                 /* подписи на бумажных карточках (только декоративно) */

  /* размеры */
  --radius-knob: 50%;
  --radius-panel: 6px;
  --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-6: 24px; --space-8: 32px;

  /* анимация */
  --ease-mech: cubic-bezier(.3, 1.4, .6, 1);  /* механическая «отдача» тумблера */
  --dur-fast: 120ms;
  --dur-med:  240ms;
}
```

### Ночной режим — «подсветка шкал»
`[data-theme="night"]` и `prefers-color-scheme: dark`: панели — тёмный анодированный алюминий (`#2a2b2d`), гравировки светлые, шкалы и LED с усиленным glow, дерево темнее. Переключатель темы — тумблер «LAMP» в шапке.

## 4. Компоненты UI-кита (`src/shared/ui`)

| Компонент | HTML-основа | Поведение |
|-----------|-------------|-----------|
| `Panel` | `<section>` | алюминиевая панель с винтами по углам (псевдоэлементы), заголовок-гравировка |
| `PushButton` | `<button>` | выпуклая, при `:active` — `--bevel-pressed` + сдвиг на 1px; варианты `primary` (с LED), `secondary` |
| `ToggleSwitch` | `<input type="checkbox" role="switch">` | металлический тумблер вверх/вниз с подписями ON/OFF, LED рядом; анимация `--ease-mech` |
| `RotarySelector` | группа `<input type="radio">` | поворотный переключатель с 2–5 метками; управление стрелками; клик по метке |
| `Led` | `<span role="status">` | состояния `on/off/ok/warn/blink`; цвет всегда дублируется текстом/aria-label |
| `LcdDisplay` | `<output>` | моноширинный зелёный текст на стекле, для счётчиков и дат |
| `VuMeter` | `<progress>`/`<meter>` | стрелочный индикатор прогресса синка/импорта |
| `EngravedInput` | `<input>` | утопленное поле в металлической рамке |
| `RecordSleeve` | `<article>` + `<img>` | конверт с обложкой, «потёртости» на краях; hover — пластинка выдвигается на 30% |
| `IndexCard` | `<article>` | бумажная карточка исполнителя, лёгкий случайный наклон ±0.6° (детерминированно от MBID) |
| `TapeLabel` | `<span>` | бумажная наклейка-бейдж для типа релиза (ALBUM, EP, feat.) |
| `CassetteDropzone` | `<input type="file">` + label | зона drag&drop |
| `Spinner` | — | вращающаяся пластинка (с `prefers-reduced-motion` — пульсирующий LED) |

Компоненты чисто презентационные (View в терминах MVC, см. [04-frontend.md](04-frontend.md)), принимают данные только через props.

## 5. Компоновка

- Десктоп: «стойка» по центру, max-width 1200px, слева и справа — деревянные боковины; вверху — шапка-ресивер с LCD (дата последнего синка, число новинок) и навигацией в виде клавиш-переключателей источника (FEED / ARTISTS / IMPORT / SETTINGS).
- Мобильные (< 768px): боковины скрываются, навигация — нижняя панель из клавиш, полка пластинок — 2 колонки, тумблеры сохраняют размер ≥ 44×44 px.

## 6. Доступность и ограничения

- Контраст текста ≥ 4.5:1 на всех фактурах — проверяется для каждого токена пары «текст/поверхность»; гравированный текст — не светлее `--text-engraved`.
- Цвет никогда не единственный носитель смысла: LED сопровождается подписью или `aria-label`.
- Видимый `:focus-visible` — оранжевое свечение лампы вокруг контрола.
- `prefers-reduced-motion: reduce` — отключить вращения, выдвижение пластинки и «отдачу» тумблеров.
- Декоративные элементы (винты, блики, шум) — псевдоэлементы или `aria-hidden`.
- Производительность: тени и градиенты не анимируются (только `transform`/`opacity`), обложки — `loading="lazy"`, размер 250px из Cover Art Archive.
- Звук (щелчок тумблера) — не используется.

## 7. Реализация

- **CSS Modules + CSS custom properties** (не Tailwind): многослойные градиенты и тени удобнее описывать в обычном CSS, а токены дают единый источник.
- Шрифты — Google Fonts (IBM Plex Sans, IBM Plex Sans Condensed, Share Tech Mono, Caveat), `font-display: swap`.
- Storybook для UI-кита: каждый компонент во всех состояниях и обеих темах; визуальные регрессии — Playwright screenshots.
- Прежде чем верстать экраны — собрать UI-кит и одну эталонную страницу (Настройки), утвердить внешний вид.
